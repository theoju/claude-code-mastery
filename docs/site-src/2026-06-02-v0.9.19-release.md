# v0.9.19 — /btw counter unblend + plan archival

`package.json` moved `0.9.18` → `0.9.19` in [PR #120](https://github.com/theoju/claude-code-self-assessment/pull/120).
The version bump itself is a one-line diff; the release exists to cut a tag
over two prior merges that were sitting on `main`:

- **CCE-78: unblend `cliBtwUseCount` from `btwCommandUses`.** The Memory
  Execution scorer's `/btw` numerator used to `Math.max` a cumulative
  all-time invocation count (`~/.claude.json`'s `btwUseCount`) into a
  30-day windowed session-coverage counter (`signalsSummary.btwCommandUses`).
  That blend violated the project's cumulative-vs-windowed counter rule
  (see CLAUDE.md's "Don't blend cumulative all-time counters into windowed
  ratio surfaces") — it overstated recent `/btw` adoption and drifted
  upward with account age rather than tracking actual recent posture. The
  fix exposes the cumulative figure as its own field,
  `cliBtwUseCountAllTime`, and reroutes the `btw-side-channel` rubric
  predicate to read from it instead of blending it into
  `btwCommandUses`. The two fields now live side by side in
  `signalsSummary`: one windowed, one cumulative, neither substituting for
  the other.
- **Plan archival.** A housekeeping merge moved the landed CCE-72 and
  CCE-76 plans into the archived plans directory — routine cleanup, no
  behavior change.

## Why this shipped as a release

The `/btw` blend was a scoring-honesty bug: it made the Memory Execution
dimension look better than actual recent practice warranted, for any
account old enough to have accumulated lifetime `/btw` invocations. Once
the unblend landed on `main`, cutting `0.9.19` closes the loop so anyone
tracking releases (rather than commits) picks up the corrected number on
their next `npm install` / pull.

## Follow-up

The unblend is a targeted fix, not the final shape of the Memory Execution
scorer — the original numerator was already summing signals across
mismatched semantic classes (`/btw`, `/clear`, `/compact`, `/rewind`) before
this fix, and `/btw` was only the most visible offender. A full redesign
of that scorer's numerator, restricted to matched session-coverage
signals, is filed as **CCE-79** and tracked separately from this release.
