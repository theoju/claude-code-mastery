# v0.9.18 release notes

PR #117 is a version bump only — `package.json` moved to `0.9.18` with no
accompanying source diff. It marks the release cut for 13 PRs merged since
v0.9.17, headlined by **CCE-76**: Execution scoring now covers all twelve
rubric dimensions.

## What actually shipped (in the PRs this release cuts)

The substantive work lives in the constituent PRs, not in #117 itself. The
headline change:

- **Memory & Context Management** and **Terminal & Customization** moved off
  `noTelemetry()` and onto real transcript-backed ratio scorers. Before
  CCE-76, these two dimensions were the last ones whose Execution score was
  unmeasured by construction — the radar rendered them in italics with a
  footnote rather than a number.
- Both new scorers consume the **posture-command coverage signals** that
  CCE-71 introduced: transcript command counts gated to sessions classified
  as `interactive_cli` or `"unknown"` (the conservative fallback — see
  `POSTURE_COMMANDS` / `VOLUME_COMMANDS` in `scripts/_usage-data.mjs`). The
  denominator is the new `interactive_or_unknown` session universe
  (`sessionsByKind.interactive_cli + sessionsByKind.unknown`), not the full
  `all_sessions` set — consistent with the project's rule that posture
  ratios must restrict their denominator to sessions where the user's
  behavior is actually observable.
- This is the same shape already used by `learning` (the `★ Insight` banner
  signal) and `parallel` (worktree usage): pull a transcript-derived signal
  into what is nominally a "cooked telemetry" Execution axis. CCE-76 applies
  that precedent to the two dimensions that previously had none.
- **Model & Effort Tuning** stays the one deliberately partial dimension: the
  Opus-usage half is scored from transcripts, but effort level (`/effort
  max` and friends) remains settings-only and isn't retroactively pulled
  into Execution. After this release, italic "unmeasured" labels on the
  radar apply only to dimensions whose Execution score returns
  `gapReason !== null` — e.g., a window with zero interactive sessions —
  not to a fixed set of dimensions that can never be measured.

## Why this release exists

Formalizing the cut at `0.9.18` gives the CCE-76 work (and the twelve other
merged PRs riding along) a single shippable reference point — a tag and a
release you can point a "what changed and why" question at, rather than
asking someone to diff thirteen individual PRs.

## What this release does *not* touch

PR #117 itself changes only the version string. No scorer, signal, or
frontend code shipped in this PR — everything described above landed in the
PRs it's cutting a release for (referenced from this repo's CLAUDE.md under
CCE-76 / PR #116). If you're auditing behavior, read those PRs directly;
this page documents the release boundary, not the implementation.
