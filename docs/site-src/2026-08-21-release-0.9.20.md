# Release: v0.9.20

`package.json` now reads `0.9.20`. [PR #200](https://github.com/theoju/claude-code-self-assessment/pull/200)
is the release-branch PR that cuts the tag — per the project's release
convention, it's a version-bump-only commit (just `package.json` and
`package-lock.json`) that doesn't ship any new code of its own. What it
ships is the *tag*: 20 commits already merged to `main` since v0.9.19,
73 files changed, +13,856/-1,092.

The substantive work landed in its own PRs earlier in the cycle. This
page is a pointer, not a duplicate — read the linked material for the
actual behavior changes.

## What's in this tag

**Measurement-honesty pass (CCE-161, CCE-162, CCE-163, CCE-164).** Four
defects where the dashboard scored a countable stand-in rather than the
property it named. CCE-161 rewrote the CLAUDE.md audit's `commands`
criterion to count executable command lines and follow linked doc files,
instead of counting fenced blocks — which had penalised extracting content
into linked files. CCE-162 added the repository's first CI for application
code and repaired a lint script that had been dead since Next 16. CCE-163
widened the Memory Execution numerator to the union of sessions showing any
deliberate context management, including external memory tooling. CCE-164
corrected posture-denominator dilution caused by misclassified sessions —
an unrecognized `entrypoint` value falling through to `unknown`, which the
`interactive_or_unknown` universe admits into the denominator.

**Memory Execution numerator redesign (CCE-79, [PR #128](https://github.com/theoju/claude-code-self-assessment/pull/128)).**
Restricted the numerator to session-coverage signals rather than mixing
cumulative and per-session counters in the same sum.

**mkdocs docs site + GitHub Pages publishing (CCE-81/[#121](https://github.com/theoju/claude-code-self-assessment/pull/121),
CCE-82/[#125](https://github.com/theoju/claude-code-self-assessment/pull/125)).**
The published docs site now builds from `docs/site-src/` and deploys to
GitHub Pages — this page is part of that pipeline.

**Dashboard retheme ([#177](https://github.com/theoju/claude-code-self-assessment/pull/177)).**
A graphite/electric-blue visual pass across the dashboard.

## Verifying the tag

`package.json:version` reads `0.9.20`, consistent with the tag this PR
cuts. Per the project's release-flow convention, the tag itself — not
the version-bump commit — is the user-facing artifact; the commit just
keeps `package.json` from drifting out of sync with it.

## Where to look for detail

Each headline item above has its own PR and, where applicable, its own
spec under `docs/superpowers/specs/`. This release note intentionally
doesn't restate their content — treat it as an index entry for "what
shipped in 0.9.20," not as the record of *how* it shipped.
