- PR #110: Implemented a per-command posture-vs-volume partition in scripts/_usage-data.mjs. Posture commands (/color, /voice, /focus, /btw, /clear, /compact, /simplify, /rewind, /fewer-permission-prompts) are now counted from transcripts only when the session kind is interactive_cli or unknown, eliminating false positives from observer and SDK-orchestrated sessions that echoed the primary session's command-name markup. Volume commands (/loop, /schedule, /babysit, /go, /batch) continue to be counted across every session kind. A fail-loud assertCommandPartition assertion runs at module load to catch partition drift (disjointness, missing classification, dead classification). Two posture threshold probes (simplifyCommandUses, rewindCommandUses) dropped to zero — this was the spec's predicted risk path, as those counts were entirely observer-session inflation rather than genuine user usage.
