- PR #122: Records two operational lessons discovered during the PR #121 mkdocs-upgrade deploy incident: (1) `actions/configure-pages@v6`'s `enablement: true` does not actually bootstrap GitHub Pages on a first deploy because the workflow's default `GITHUB_TOKEN` lacks admin scope, and `permissions:` blocks can only restrict (never expand) that token — the real fix is a one-time `gh api -X POST repos/<owner>/<repo>/pages -f build_type=workflow` call (or the equivalent Settings UI toggle) before the first deploy; and (2) monitor/poll scripts must avoid zsh's read-only built-in parameters `status`/`pipestatus`, which crash the shell if assigned to inside a loop, silently masking successful deploys. The PR updates CLAUDE.md Conventions with both lessons and appends a post-implementation correction to the existing mkdocs-upgrade spec and plan docs.
