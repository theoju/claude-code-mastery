## v0.9.18

Release-only version bump (PR #117) — no code changes in the PR itself,
but it tags a checkpoint bundling 13 PRs merged since v0.9.17. The two
headline fixes:

- **CCE-76**: Memory & Context Management and Terminal & Customization
  now have real Execution scorers. Both dimensions previously reported
  `noTelemetry` on the Execution axis; they now use gated ratio scoring
  against the `interactive_cli ∪ unknown` session universe, closing the
  last two unmeasured Execution gaps. Model & Effort Tuning remains the
  only *partially*-measured dimension (Opus usage is scored from
  transcripts; effort level stays settings-only).
- **CCE-71**: posture-vs-volume command partitioning. Posture commands
  (`/color`, `/btw`, `/clear`, `/compact`, etc.) are now counted from
  transcripts only for `interactive_cli`/`unknown` sessions, so
  `observer`/`sdk_orchestrated`/`subagent` sessions can no longer
  inflate posture counters. Volume commands (`/loop`, `/schedule`,
  `/batch`, etc.) are unaffected and still counted across every scanned
  session kind.

If you're on an older tag, the version bump alone won't change your
scores — pull the individual PRs' fixes by upgrading past v0.9.18 to
pick up the corrected Execution measurements.
