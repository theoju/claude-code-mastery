- PR #122: Post-merge documentation update recording two operational lessons discovered during the PR #121 GitHub Pages deploy incident: (1) `actions/configure-pages@v6`'s `enablement: true` does not actually bootstrap GitHub Pages on a first deploy because the workflow's `GITHUB_TOKEN` lacks admin scope needed to call the Pages API — the fix is a one-time `gh api -X POST .../pages -f build_type=workflow` call (or the equivalent Settings UI toggle) before the first deploy; and (2) monitor scripts written for zsh must avoid assigning to the shell's read-only `status`/`pipestatus` built-ins, which crash the shell and cause the monitor to exit non-zero with no emitted events — masking, rather than reporting, deploy failures. The PR updates `CLAUDE.md` Conventions plus the mkdocs-upgrade plan and spec docs with these findings; no code changes.
