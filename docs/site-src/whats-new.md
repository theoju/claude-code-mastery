- PR #122: Post-merge follow-up to PR #121 (CCE-81) recording three durable lessons from the mkdocs GitHub Pages deploy incident: (1) `actions/configure-pages@v6 enablement: true` does not bootstrap GitHub Pages on a first deploy because the workflow GITHUB_TOKEN lacks admin scope — the correct fix is a one-off `gh api -X POST repos/.../pages -f build_type=workflow` call or a UI toggle; (2) monitor scripts must avoid zsh read-only built-ins (`status`, `pipestatus`) by renaming loop locals or using a bash shebang, since assigning to either crashes the shell silently; (3) a monitor exiting non-zero with no event lines emitted is almost always a script bug, not a failure of the watched system.
