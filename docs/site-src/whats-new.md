- PR #122: Records two operational lessons discovered during the PR #121 / CCE-81 GitHub Pages deploy incident. First: actions/configure-pages@v6's `enablement: true` does not actually bootstrap Pages on a first deploy, because the workflow's GITHUB_TOKEN lacks the admin scope needed to call the Pages API and `permissions:` blocks can only restrict, never expand, that token's scopes — the fix is a one-time `gh api -X POST .../pages -f build_type=workflow` call (or the equivalent Settings > Pages UI toggle) run by an admin login before the first deploy. Second: poll-loop monitor scripts must declare `#!/usr/bin/env bash` (or otherwise avoid zsh) because zsh treats `status` and `pipestatus` as read-only built-in parameters, so assigning to either inside a loop crashes the shell and silently masks successful deploys. Both lessons are added as new CLAUDE.md Conventions bullets and cross-referenced from the mkdocs-upgrade spec's 'Post-implementation correction' section and the plan's recovery section.
