## v0.9.18

Release checkpoint (PR #117) — a version bump with no source diff of
its own (`package.json` only). It packages together 13 PRs that
landed since v0.9.17, headlined by:

- **All 12 rubric dimensions now have Execution scorers (CCE-76, PR
  #116).** Memory & Context Management and Terminal & Customization
  were the last two holdouts on the radar's italic "unmeasured"
  treatment; both now consume transcript-derived posture-command
  coverage signals gated against the `interactive_or_unknown` session
  universe (`sessionsByKind.interactive_cli + sessionsByKind.unknown`)
  — the same shape `learning` and `parallel` already used. Model &
  Effort Tuning remains the one dimension that's only partially
  measured: Opus usage is scored from transcripts, but effort level
  stays settings-only. On the radar, the italic "unmeasured" label now
  applies strictly to dimensions whose Execution score returns a
  non-null `gapReason` (for example, zero interactive sessions in the
  scoring window) — not to a fixed list of dimensions.
- **Posture/volume command partition (CCE-71, PR #110).** Command
  counting now honors a hard split between posture commands
  (`/color`, `/voice`, `/focus`, `/btw`, `/clear`, `/compact`,
  `/simplify`, `/rewind`, `/fewer-permission-prompts`) — counted from
  transcripts only when a session classifies as `interactive_cli` or
  the conservative `"unknown"` fallback — and volume commands
  (`/loop`, `/schedule`, `/babysit`, `/go`, `/batch`), which count
  across every scanned session kind. A fail-loud assertion at module
  load catches drift between the two sets.

If you're pulling `main` past this tag, the practical effect is that
your dashboard's radar should show fewer italicized dimensions than
before — check the Methodology page's per-scorer breakdown if a
dimension you expected to be measured is still showing as unmeasured.
