## 2026-06-02 — Docs site now published via mkdocs

This page you're reading is the first artifact of it: the
engineering-docs-agent integration for this repo flipped from
`framework: none` to `framework: mkdocs` ([PR #121](https://github.com/theoju/claude-code-self-assessment/pull/121)),
and the docs now build to a Material-theme site at
<https://theoju.github.io/claude-code-self-assessment/>.

What changed under the hood:

- **`mkdocs.yml`** — Material theme with `navigation.tabs`,
  `navigation.sections`, `toc.follow`, and search-suggest; the `search`,
  `awesome-pages`, and `literate-nav` plugins are enabled, with
  `literate-nav` reading the nav order from `docs/site-src/SUMMARY.md`.
  `requirements-docs.txt` pins the Python build dependencies.
- **Two CI workflows** — `docs-agent-pages.yml` deploys to GitHub Pages
  on every push to `main` that touches `docs/site-src/**`, `mkdocs.yml`,
  or `requirements-docs.txt`; `docs-build-check.yml` runs `mkdocs build
  --strict` on every PR touching the same paths, so a broken link or
  malformed page fails the PR instead of the deploy.
- **Docs moved** — the flat `docs/*.md` files were `git mv`'d into
  `docs/site-src/`, mkdocs' `docs_dir`. Nine relative links that pointed
  outside the new `docs_dir` (into `docs/superpowers/`, `.claude/`, etc.)
  were rewritten to absolute `github.com/.../blob/main/...` URLs, since
  `mkdocs build --strict` rejects link targets it can't resolve inside
  `docs_dir`.
- **`.engineering-docs-agent/config.yml`** — five fields flipped to
  match: `docs.framework`, `docs.whats_new_file`,
  `docs.lens_paths.core`, `publishing.base_url`, and
  `publishing.build_workflow`.
- Six other files had their `docs/` path references retargeted to
  match the move, and 21 new vitest cases now cover the migration, the
  scaffold, and the config contract.

The config file had documented this exact upgrade path since it was
first written — "swap framework to mkdocs and fill in base_url +
build_workflow" — under ticket CCE-81. Three pre-execution review
passes (correctness, completeness, test-rigor) caught real blockers
before merge: broken links under `.claude/`, path references in
`.claude/commands/` that the initial pass missed, and a missing
PR-level build gate. All three were fixed before this shipped.
