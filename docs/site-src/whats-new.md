### Onboarding note

`actions/configure-pages@v6 enablement: true` does **not** auto-bootstrap
GitHub Pages on first deploy. Before the first workflow run you must call:

```bash
gh api -X POST repos/<owner>/<repo>/pages -f build_type=workflow
```

or enable Pages via **Settings → Pages → Source = GitHub Actions** in the
repo UI. After Pages is bootstrapped once, all subsequent push-triggered
deploys work automatically. See `CLAUDE.md` for the full incident write-up.
